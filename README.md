# AIAA(AI투에이) · AI Ads Assistant — 데모

GPT 광고 어시스턴트(모두의창업 2차) 컨셉 데모. 단일 HTML, 의존성 없음.

## 실행

```bash
cd ai_ads_assistant
python3 -m http.server 8000
# → http://localhost:8000
```

또는 `index.html`을 브라우저로 바로 열어도 된다.

## 파일

- `index.html` — 제품 데모 대시보드 (다크, 2뷰: 대시보드 / 광고 집행)
- `intro.html` — 서비스 소개 페이지 (라이트, 제출·공유용): 히어로 → 문제 3카드 → 측정×광고 사이클 다이어그램 + 운영 모드 3종 → 기능 상세 3단 → 확장 로드맵(GPT→구글→코파일럿→네이버) → 이용 4단계

## 데모(index.html) 화면

1. **대시보드** — KPI 카운트업 4종, 타겟별 언급 현황(애니메이션 바), 추천 액션 3카드
2. **언급 현황** — 실시간 측정 로그(타이핑 애니메이션), 질문 단위 언급 O/X 표, 측정 설계
3. **광고 집행** — 타겟 아코디언 리스트(요약 행 → 확장 시 측정 프롬프트 + 힌트 초안) → 광고 세팅/일괄 등록
4. **예산 최적화** — 질문별 본답변/광고/운영 제안 표, ON/OFF 토글 시 예산 이동 애니메이션
5. **리포트** — 8주 언급률 추이(SVG 라인 드로잉), 월간 한 장 요약

## 용도·주의

- 지원서 첨부 스크린샷 / 소개영상 화면 녹화 / 2R 시연용.
- 모든 수치는 예시(헬씨온 영양제몰 — 가상 브랜드). 화면마다 "데모·예시" 표기 유지할 것.
- 실제 광고 등록·측정 기능 없음 (컨셉 데모).
